# onec-error-handling — обработка ошибок 1С

## Когда использовать

- Любой Tool вернул `{"ok": false, "error": "..."}`.
- Пользователь сообщает, что в 1С что-то не так.

## Как реагировать

1. **Прочитайте суть ошибки**, а не пересказывайте текст целиком. Ошибки уже
   сформулированы для пользователя (проверки Tools: дубликаты, ставки НДС,
   проведённые документы, отсутствие ссылок).
2. **Объясните понятным языком** и предложите следующий шаг:
   - «контрагент уже существует (Ref_Key …)» → используйте существующего;
   - «найдены непроведённые счёта за сегодня» → доработать существующий счёт
     или новый по подтверждению (`force_new=true`);
   - «ставка НДС недопустима» → покажите допустимые варианты, спросите замену;
   - «документ проведён в 1С» → изменение недопустимо, нужна помощь бухгалтера;
   - «1С недоступна / таймаут / авторизация» → проблема инфраструктуры,
     повторите запрос позже или проверьте учётные данные.
3. **Не повторяйте создающий вызов вслепую**: запись могла пройти до ошибки
   (сетевой сбой после POST). Сначала повторный поиск/чтение, затем решение.
4. **Не исправляйте данные молча**: замена ставки, контрагента, сумм — только
   после явного ответа пользователя.

## Эскалация

К бухгалтеру/пользователю, а не повторными вызовами:

- ошибки проведения (счета учёта, остатки, взаиморасчёты);
- расхождения уже проведённых документов с ожиданиями;
- повторяющаяся ошибка 1С, причина которой не ясна из текста.
