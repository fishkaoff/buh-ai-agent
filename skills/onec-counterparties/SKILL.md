# onec-counterparties — контрагенты

## Когда использовать

- Пользователь назвал компанию/ИП: счёт, договор, документ на контрагента.
- «Найди контрагента…», «создай контрагента…».

Tools: `find_counterparty`, `create_counterparty`.

## Порядок работы

1. **Поиск.** `find_counterparty` с наименованием и/или ИНН. **ИНН главнее наименования**:
   если известен ИНН — ищите по нему (наименование может отличаться от сказанного).
   Поиск по наименованию устойчив к формату: пробелы, кавычки, регистр и юридическая
   форма не важны («Логистик Плюс» найдёт «ЛогистикПлюс») — передавайте наименование,
   как сказал пользователь, не переспрашивая «точное наименование» ради поиска.
2. **Найден один** — используйте его `ref_key`. **Несколько** — покажите список
   (наименование + ИНН) и уточните, кого имел в виду пользователь.
3. **Не найден** — уточните у пользователя, создать ли нового; для создания
   нужно наименование (как в документах), желательно ИНН.
4. **Создание.** `create_counterparty`. Tool сам проверяет дубликаты: если
   контрагент уже существует, вернётся ошибка с его `ref_key` — используйте
   существующего, не создавайте повторно.

## Правила

- Ref_Key контрагента берите только из результатов Tools, не придумывайте.
- Не создавайте контрагента без явного согласия пользователя («создать нового?»).
- Не редактируйте существующих контрагентов: Tools приложения этого не умеют —
  предложите пользователю поправить вручную в 1С.
