# onec-nomenclature — номенклатура

## Когда использовать

- Пользователь назвал позиции для счёта/документа.
- «Найди номенклатуру…», «добавь услугу/товар…».

Tools: `find_nomenclature`, `create_nomenclature`.

## Порядок работы

1. `find_nomenclature` по подстроке наименования (по каждой позиции из запроса).
2. **Найдена** — используйте её `ref_key`. Несколько похожих — уточните у пользователя.
3. **Не найдена** — уточните у пользователя, создать ли новую, и это услуга или
   товар. Тип важен: услуга не требует склада при реализации, товар — требует.
4. **Создание.** `create_nomenclature` (`is_service=true` — услуга, `false` — товар).
   Tool проверяет дубликаты по наименованию: если позиция есть, вернётся ошибка
   с её `ref_key` — используйте существующую.

## Правила

- В сценарии `create_sales_invoice` номенклатура ищется и создаётся автоматически
  по наименованиям позиций — отдельный поиск нужен, только если пользователь
  спрашивает о позициях отдельно.
- Наименование — как назвал пользователь, без «улучшений»; то, что попадёт в документ.
- Ref_Key позиции — только из результатов Tools.
