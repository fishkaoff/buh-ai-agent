# onec-contracts — договоры контрагентов

## Когда использовать

- Подбор договора перед созданием счёта/реализации.
- «Найди договор…», «создай договор…».

Tools: `find_contract`, `create_contract`.

## Порядок работы

1. `find_contract` по `counterparty_key` (Ref_Key из `find_counterparty`) и виду.
   Вид договора: `СПокупателем` — продажи (счета, реализации), `СПоставщиком` — закупки.
2. **Договоры найдены** — выберите подходящий (не закрытый: `closed=false`);
   если подходит несколько — уточните у пользователя.
3. **Договоров нет** — предложите создать. Счёт технически возможен и без
   договора, но для корректных взаиморасчётов договор нужен.
4. **Создание.** `create_contract`: номер обязателен — договор без номера
   («б/н») не создаётся. Номера договоров сквозные, общие на всех контрагентов:
   если номер не указан, Tool сам подставит кандидата (max числовых номеров по
   ВСЕМ договорам базы + 1). Если Tool вернул ошибку «номер не удалось
   определить» или «номер занят другим договором» — запросите номер у
   пользователя. Если договор с таким номером и видом уже есть у этого
   контрагента, Tool вернёт его с `already_exists=true` — используйте
   существующий.

## Правила

- Договор принадлежит контрагенту: `counterparty_key` — только из результатов Tools.
- Номер договора обязателен, «б/н» не создаём. Номера общие на всех КА: номер,
  занятый договором другого контрагента, использовать нельзя — нужен другой номер.
- Дату договора, если пользователь не назвал, не спрашивайте — сегодня.
- Создание договора оформляйте в рамках той же операции, что и счёт.
