# Карта метаданных конфигурации 1С (база ai_agent)

Исследовано 10.11.2026 через `read_schema_describe_entity`, `$metadata` и фактические записи. Конфигурация: **1С:Бухгалтерия предприятия 3.0** (признаки: план счетов Хозрасчетный, документный состав, `ЭтоУниверсальныйДокумент` у реализации). Обновлять по факту изменения конфигурации (Skill `onec-metadata`).

## 1. Справочники

### Catalog_Контрагенты
- Ключевые реквизиты: `Description` (наименование), `НаименованиеПолное`, `ИНН`, `КПП`, `ЮридическоеФизическоеЛицо` (переч. `ЮридическоеФизическоеЛицо`: `ЮридическоеЛицо`, `ФизическоеЛицо`), `IsFolder`, `Parent_Key`, `DeletionMark`, `ОсновнойБанковскийСчет_Key`, `ОсновноеКонтактноеЛицо_Key`, `Комментарий`, `Самозанятый`, `ИндивидуальныйПредприниматель`.
- Табличные коллекции: `КонтактнаяИнформация`, `ДополнительныеРеквизиты`, `ИсторияКПП`, `ИсторияНаименований`.
- Подчинённые: `Catalog_ДоговорыКонтрагентов`, `Catalog_БанковскиеСчета`, `Catalog_КонтактныеЛица`, банковские карты.
- Обязательный минимум при создании (проверено): `Description`, `ИНН`, `ЮридическоеФизическоеЛицо`. `Code` 1С присваивает сам (`00-0000NN`).

### Catalog_ДоговорыКонтрагентов (подчинён контрагенту через `Owner_Key`!)
- Реквизиты: `Description`, `Номер` (строка, **не нумеруется 1С через OData**), `Дата`, `ВидДоговора`, `Организация_Key`, `ВалютаВзаиморасчетов_Key`, `ТипЦен_Key`, `СрокДействия`, `СрокОплаты`, `УстановленСрокОплаты`, `СпособЗаполненияСтавкиНДС` (переч. `СпособыЗаполненияСтавкиНДС`: `Автоматически`, `БезНДС`, `ИзКарточкиНоменклатуры`), `СтавкаНДС`, `СуммаВключаетНДС`, `Руководитель_Key`, `ДоговорЗакрыт`, `Комментарий`.
- Перечисление `ВидыДоговоровКонтрагентов`: `Прочее`, `СКомиссионером`, `СКомиссионеромНаЗакупку`, `СКомитентом`, `СКомитентомНаЗакупку`, `СПокупателем`, `СПоставщиком`, `СТранспортнойКомпанией`, `СФакторинговойКомпанией`.
- Нумерация (наблюдение): существующие договоры — сквозные номера 1..3 с `Description` «N от ДД.ММ.ГГГГ»; `Code` — авто (`00-0000NN`).

### Catalog_Организации
- `Description`, `НаименованиеПолное`, `НаименованиеСокращенное`, `ИНН`, `КПП`, `ОГРН`, `ЮридическоеФизическоеЛицо`, `Префикс`, `ОсновнойБанковскийСчет_Key`, `КодОКВЭД(2)`, `ВариантНаименованияДляПечатныхФорм`, коллекция `КонтактнаяИнформация`.
- В базе одна: «Агентов Т. Т. ИП» (ИНН 1209328142), `Ref_Key aa0ad33a-dba9-11f1-9a8f-a02942832943`.

### Catalog_Номенклатура
- `Description`, `НаименованиеПолное`, `Артикул`, `Услуга` (Boolean), `ВидНоменклатуры_Key`, `ЕдиницаИзмерения_Key`, `НоменклатурнаяГруппа_Key`, `ВидСтавкиНДС` (переч. `ВидыСтавокНДС`), `СтатьяЗатрат_Key`, `Parent_Key` (иерархия), `IsFolder`, `DeletionMark`, `ПризнакПредметаРасчета` (переч. `ПризнакиПредметаРасчета`).
- `УдалитьСтавкаНДС` — устаревший, не использовать.
- **Автозаполнение при POST (проверено)**: 1С сама подставляет вид (по флагу `Услуга`), единицу («шт»), номенклатурную группу и `ВидСтавкиНДС` («Общая»).
- `Catalog_ВидыНоменклатуры`: Товары, Услуги, Материалы, Продукция, … (полный список — Skill `onec-reference-data`, references).

### Catalog_КлассификаторЕдиницИзмерения
- `Description` («шт», «кг», «л», «1000 руб»), `Code` (ОКЕИ). Не пополнять без пользователя.

### Catalog_Валюты
- Код 643 — руб.; Ref_Key `ea9005c5-7320-11ec-95fd-0242ac120003`.

### Catalog_Склады
- «Основной склад» (`34394c2a-7321-11ec-8111-0242ac120003`). В счёте `Склад_Key` необязателен.

### Catalog_БанковскиеСчета
- Владелец — полиморфный (`Owner` + `Owner_Type`); поля `НомерСчета`, `Банк_Key`, `Description`. Банковский счёт организации в документах продаж — реквизит `СтруктурнаяЕдиница_Key`.

## 2. Документы

### Document_СчетНаОплатуПокупателю (+ _Товары, _ВозвратнаяТара)
- Шапка: `Организация_Key`, `Контрагент_Key`, `ДоговорКонтрагента_Key`, `ВалютаДокумента_Key`, `СтруктурнаяЕдиница_Key` (банк), `Склад_Key`, `СуммаВключаетНДС`, `ДокументБезНДС`, `СуммаДокумента`, `ВидОперации` (переч. `ВидыОперацийСчетаПокупателю`: `ТоварыИУслуги`, `ОсновныеСредства`), `Ответственный_Key`, `Комментарий`.
- `_Товары`: `Номенклатура` + `Номенклатура_Type` (составная!), `Содержание`, `Количество`, `Цена`, `Сумма`, `ПроцентСкидки`, `СуммаСкидки`, `СтавкаНДС`, `СуммаНДС`.
- Нумерация годовая с префиксом: `0000-0000NN`. Проводок не делает (проведение флага не требует для участия в связях).
- Счёт не хранит сумму НДС шапки; НДС — на строках.

### Document_РеализацияТоваровУслуг (+ _Товары, _Услуги, _АгентскиеУслуги, _ЗачетАвансов, …)
- Шапка: `ВидОперации` (переч. `ВидыОперацийРеализацияТоваров`: `Товары`, `Услуги`, `ПродажаКомиссия`, `ОтгрузкаБезПереходаПраваСобственности`, `ПередачаТоваров`, `ВыкупТоваровКомиссионером`, `СтроительныеРаботы`, `Оборудование`), `Склад_Key`, `СчетНаОплатуПокупателю_Key` (**ссылка на счёт-основание**), `СчетУчетаРасчетовСКонтрагентом_Key` (62.01), `СчетУчетаРасчетовПоАвансам_Key` (62.02), `БанковскийСчетОрганизации_Key`, `СуммаВключаетНДС`, `ДокументБезНДС`, `СуммаДокумента`, `СпособЗачетаАвансов` (переч.: `Автоматически`, `НеЗачитывать`, `ПоДокументу`), `ЭтоУниверсальныйДокумент` (флаг УПД).
- `_Товары`: `Номенклатура_Key` (не составная), `ЕдиницаИзмерения_Key`, `Количество`, `Цена`, `Сумма`, `СтавкаНДС`, `СуммаНДС`, `СчетУчета_Key` (41), `СчетДоходов_Key` (90.01), `СчетРасходов_Key` (90.02), `СчетУчетаНДСПоРеализации_Key` (90.03), `СчетНаОплатуПокупателю_Key`.
- `_Услуги`: `Номенклатура_Key`, `Содержание`, `Количество`, `Цена`, `Сумма`, `СтавкаНДС`, `СуммаНДС`, `СчетДоходов_Key`, `СчетРасходов_Key`, `СчетУчетаНДСПоРеализации_Key`, `СчетНаОплатуПокупателю_Key`.
- Проводки при проведении (проверено): Дт 62.01 Кт 90.01.1 (выручка); Дт 90.03 Кт 68.02 (НДС — только если `СуммаНДС` строк заполнен); Дт 90.02 Кт 41 (себестоимость, для товаров).
- **УПД — печатная форма этого документа** (см. Skill `onec-upd`).

### Document_СчетФактураВыданный
- Шапка: `ВидСчетаФактуры` (переч. `ВидСчетаФактурыВыставленного`: `НаРеализацию`, `НаАванс`, `Корректировочный`, `КорректировочныйНаАванс`, `НаСуммовуюРазницу`, `НалоговыйАгент`, `НаАвансКомитента`, `СводнаяСправка`, `КорректировочнаяСправка`), `КодВидаОперации` («01» — реализация), `ДокументОснование` + `_Type` (составная), `ДокументыОснования` (таблица), `ДатаВыставления`, `СтавкаНДС`, `СуммаДокумента`, `СуммаНДСДокумента`, `СчетФактураБезНДС`, `Выставлен`.
- Создаётся на основании реализации (MCP `write_sales_create_issued_invoice` наследует реквизиты).

## 4. Связи (граф)

```
Catalog_Организации ──< все документы (.Организация_Key)
Catalog_Контрагенты ──< Catalog_ДоговорыКонтрагентов (Owner_Key)
Catalog_ДоговорыКонтрагентов >-- Organization_Key, ВалютаВзаиморасчетов_Key
Document_СчетНаОплатуПокупателю >-- Контрагент_Key, ДоговорКонтрагента_Key, СтруктурнаяЕдиница_Key (банк)
Document_РеализацияТоваровУслуг >-- Контрагент_Key, ДоговорКонтрагента_Key, СчетНаОплатуПокупателю_Key, Склад_Key
Document_РеализацияТоваровУслуг._Товары/_Услуги >-- Номенклатура_Key, СчетНаОплатуПокупателю_Key, счета учёта (41/90.01/90.02/90.03)
Document_СчетФактураВыданный >-- ДокументОснование (_Type=Document_РеализацияТоваровУслуг), Организация_Key, Контрагент_Key
Регистр накопления ОплатаСчетов -- движения платежей со ссылкой на счёт (для get_unpaid_invoices)
```

## 5. Обязательное для проведения (практика)

- Реализация услуг: контрагент, договор (для 62), вид операции, строки с номенклатурой-услугой, суммы, ставка НДС + **СуммаНДС строк** (иначе нет проводки НДС), счета доходов/расходов/НДС (MCP подставляет 90.01.1/90.02.1/90.03).
- Реализация товаров: + склад и остатки товара (`read_analytics_get_inventory`), иначе красное сальдо 41.
- Счёт покупателю: проведения не требует (флаг опционален).
