# HTTP-сервис печати (PDF) — расширение конфигурации 1С

Официальные печатные формы в PDF для агента: 1С сама формирует печатную форму
штатным механизмом БСП и отдаёт её HTTP-сервисом расширения. Конфигурация не
снимается с поддержки, данные базы не засоряются присоединёнными файлами.

Приложение-агент после развёртывания вызывает:

```
GET http://<сервер>/<база>/hs/print/invoice/<Ref_Key счёта>       →  200, application/pdf
GET http://<сервер>/<база>/hs/print/realization/<Ref_Key реализации>  →  200, application/pdf (УПД)
```

Шаблон `invoice` обязателен для PDF счёта, `realization` — для PDF УПД
(агент забирает оба PDF автоматически при создании счёта; без шаблона
`realization` счёт-PDF будет получен, а УПД останется черновиком).

## Проверено в БП 3.0 (БСП 3.1.x, платформа 8.3.27)

- коллекция печатных форм в этой БСП — **ТаблицаЗначений** со стандартным
  набором колонок (`УправлениеПечатью.НужноПечататьМакет` ищет по колонке
  `ИмяВРЕГ` через `Найти(значение, колонка)`);
- `УправлениеПечатью.ПечатьДокументов` **не существует** — печать вызывается
  напрямую через менеджер печати (`Обработка.ПечатьСчетаНаОплату.Печать`);
- у `HTTPСервисЗапрос` параметры шаблона URL — свойство **`ПараметрыURL`**;
- УПД печатается **из счёта-фактуры выданного** (находится по реализации
  через ТЧ `ДокументыОснования`); идентификатор макета выбирается по дате
  документа: `УПДСтатус1_2023Кв4` / `_534` / `_981` / `УПДСтатус1`.

## Шаг 1. Расширение

Конфигуратор → «Расширения конфигурации» → «Добавить»:

- имя: `ПечатьPDF`;
- **снимите флажок «Безопасный режим»** — иначе `Записать(PDF)` и файловые
  операции упадут с ошибкой прав;
- если база работает с профилями безопасности — создайте профиль, разрешающий
  HTTP-сервис и файловые операции.

Расширение публикуется в составе базы: обновления типовой конфигурации не
затрагиваются.

## Шаг 2. HTTP-сервис

В расширении: добавить → HTTP-сервис:

- имя: `ПечатьДокументов`;
- корневой URL: `print`;
- шаблон URL №1: `/invoice/{ID}` — метод `GET`, обработчик `ПечатьPDF_СчетНаОплату`;
- шаблон URL №2: `/realization/{ID}` — метод `GET`, обработчик `ПечатьPDF_РеализацияУПД`.

## Шаг 3. Модуль сервиса (рабочая версия)

```bsl
// HTTP-сервис ПечатьДокументов (расширение ПечатьPDF)

Функция ПечатьPDF_СчетНаОплату(Запрос)

	СтрокаID = Запрос.ПараметрыURL.Получить("ID");

	Попытка
		УникальныйID = Новый УникальныйИдентификатор(СтрокаID);
	Исключение
		Возврат ОшибкаОтвета(400, "Некорректный GUID документа: " + СтрокаID);
	КонецПопытки;

	СсылкаНаДокумент = Документы.СчетНаОплатуПокупателю.ПолучитьСсылку(УникальныйID);

	// ПолучитьСсылку не проверяет существование: у «пустышки» по
	// несуществующему GUID ПолучитьОбъект() = Неопределено.
	Если СсылкаНаДокумент.ПолучитьОбъект() = Неопределено Тогда
		Возврат ОшибкаОтвета(404, "Счёт с GUID " + СтрокаID + " не найден.");
	КонецЕсли;

	Попытка
		ТабДок = ТабличныйДокументСчетаНаОплату(СсылкаНаДокумент);
	Исключение
		// Полный текст ошибки возвращаем клиенту — упрощает отладку.
		Возврат ОшибкаОтвета(500, ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
	КонецПопытки;

	Если ТабДок = Неопределено Тогда
		Возврат ОшибкаОтвета(500, "Печатная форма счёта не сформирована.");
	КонецЕсли;

	ИмяВременногоФайла = ПолучитьИмяВременногоФайла("pdf");
	ТабДок.Записать(ИмяВременногоФайла, ТипФайлаТабличногоДокумента.PDF);

	Данные = Новый ДвоичныеДанные(ИмяВременногоФайла);
	Попытка
		УдалитьФайлы(ИмяВременногоФайла);
	Исключение
	КонецПопытки;

	Ответ = Новый HTTPСервисОтвет(200);
	Ответ.УстановитьТелоИзДвоичныхДанных(Данные);
	Ответ.Заголовки.Вставить("Content-Type", "application/pdf");
	Ответ.Заголовки.Вставить(
		"Content-Disposition",
		"inline; filename=""schet_" + СтрокаID + ".pdf""");
	Возврат Ответ;

КонецФункции

// Шаблон /realization/{ID}: УПД печатается из счёта-фактуры,
// найденной по реализации.
Функция ПечатьPDF_РеализацияУПД(Запрос)

	СтрокаID = Запрос.ПараметрыURL.Получить("ID");

	Попытка
		УникальныйID = Новый УникальныйИдентификатор(СтрокаID);
	Исключение
		Возврат ОшибкаОтвета(400, "Некорректный GUID документа: " + СтрокаID);
	КонецПопытки;

	СсылкаНаДокумент = Документы.РеализацияТоваровУслуг.ПолучитьСсылку(УникальныйID);

	Если СсылкаНаДокумент.ПолучитьОбъект() = Неопределено Тогда
		Возврат ОшибкаОтвета(404, "Реализация с GUID " + СтрокаID + " не найдена.");
	КонецЕсли;

	Попытка
		ТабДок = ТабличныйДокументРеализацииУПД(СсылкаНаДокумент);
	Исключение
		Возврат ОшибкаОтвета(500, ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
	КонецПопытки;

	Если ТабДок = Неопределено Тогда
		Возврат ОшибкаОтвета(500, "Печатная форма УПД не сформирована.");
	КонецЕсли;

	ИмяВременногоФайла = ПолучитьИмяВременногоФайла("pdf");
	ТабДок.Записать(ИмяВременногоФайла, ТипФайлаТабличногоДокумента.PDF);

	Данные = Новый ДвоичныеДанные(ИмяВременногоФайла);
	Попытка
		УдалитьФайлы(ИмяВременногоФайла);
	Исключение
	КонецПопытки;

	Ответ = Новый HTTPСервисОтвет(200);
	Ответ.УстановитьТелоИзДвоичныхДанных(Данные);
	Ответ.Заголовки.Вставить("Content-Type", "application/pdf");
	Ответ.Заголовки.Вставить(
		"Content-Disposition",
		"inline; filename=""upd_" + СтрокаID + ".pdf""");
	Возврат Ответ;

КонецФункции

Функция ОшибкаОтвета(Код, Текст)

	Ответ = Новый HTTPСервисОтвет(Код);
	Ответ.УстановитьТелоИзСтроки(Текст);
	Ответ.Заголовки.Вставить("Content-Type", "text/plain; charset=utf-8");
	Возврат Ответ;

КонецФункции

// Формирование печатной формы счёта через менеджер печати Обработка.ПечатьСчетаНаОплату
// (стандартный программный интерфейс БСП; ИДМакета "СчетЗаказ" — «Счет на оплату»).
Функция ТабличныйДокументСчетаНаОплату(Ссылка)

	МассивОбъектов = Новый Массив;
	МассивОбъектов.Добавить(Ссылка);

	ОбъектыПечати = Новый СписокЗначений;
	ОбъектыПечати.Добавить(Ссылка);

	ПараметрыПечати = Новый Структура;
	ПараметрыВывода = Новый Структура;

	КоллекцияПечатныхФорм = НоваяКоллекцияПечатныхФормСервер("СчетЗаказ");

	Обработки.ПечатьСчетаНаОплату.Печать(
		МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода);

	Для Каждого ПечатнаяФорма Из КоллекцияПечатныхФорм Цикл
		Если ПечатнаяФорма.ТабличныйДокумент <> Неопределено Тогда
			Возврат ПечатнаяФорма.ТабличныйДокумент;
		КонецЕсли;
	КонецЦикла;

	Возврат Неопределено;

КонецФункции

// Формирование УПД: счёт-фактура ищется по реализации, форма выбирается по дате.
Функция ТабличныйДокументРеализацииУПД(СсылкаНаРеализацию)

	Запрос = Новый Запрос;
	Запрос.Текст =
	"ВЫБРАТЬ ПЕРВЫЕ 1
	|	СчетаФактуры.Ссылка КАК Ссылка
	|ИЗ
	|	Документ.СчетФактураВыданный.ДокументыОснования КАК СчетаФактуры
	|ГДЕ
	|	СчетаФактуры.ДокументОснование = &Реализация";
	Запрос.УстановитьПараметр("Реализация", СсылкаНаРеализацию);

	Выборка = Запрос.Выполнить().Выбрать();
	Если НЕ Выборка.Следующий() Тогда
		ВызватьИсключение "Счёт-фактура по реализации не найдена — УПД не может быть напечатан.";
	КонецЕсли;
	СсылкаНаСчетФактуру = Выборка.Ссылка;

	// Версии постановления 1137: форма выбирается по дате документа.
	ДатаДокумента = СсылкаНаРеализацию.Дата;
	Если ДатаДокумента >= Дата(2023, 10, 1) Тогда
		ИдентификаторМакета = "УПДСтатус1_2023Кв4";
	ИначеЕсли ДатаДокумента >= Дата(2021, 7, 1) Тогда
		ИдентификаторМакета = "УПДСтатус1_534";
	ИначеЕсли ДатаДокумента >= Дата(2019, 10, 1) Тогда
		ИдентификаторМакета = "УПДСтатус1_981";
	Иначе
		ИдентификаторМакета = "УПДСтатус1";
	КонецЕсли;

	МассивОбъектов = Новый Массив;
	МассивОбъектов.Добавить(СсылкаНаСчетФактуру);

	ОбъектыПечати = Новый СписокЗначений;
	ОбъектыПечати.Добавить(СсылкаНаСчетФактуру);

	ПараметрыПечати = Новый Структура;
	ПараметрыВывода = Новый Структура;

	КоллекцияПечатныхФорм = НоваяКоллекцияПечатныхФормСервер(ИдентификаторМакета);

	Обработки.ПечатьУПД.Печать(
		МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода);

	Для Каждого ПечатнаяФорма Из КоллекцияПечатныхФорм Цикл
		Если ПечатнаяФорма.ТабличныйДокумент <> Неопределено Тогда
			Возврат ПечатнаяФорма.ТабличныйДокумент;
		КонецЕсли;
	КонецЦикла;

	ВызватьИсключение "ПечатьУПД не заполнила форму «" + ИдентификаторМакета
		+ "». Счёт-фактура: " + Строка(СсылкаНаСчетФактуру)
		+ ", проведена: " + СсылкаНаСчетФактуру.Проведен
		+ ", дата документа: " + Формат(ДатаДокумента, "ДФ=dd.MM.yyyy");

КонецФункции

// Серверный конструктор коллекции печатных форм. В БСП этой сборки коллекция —
// ТаблицаЗначений со стандартными колонками (НужноПечататьМакет ищет по ИмяВРЕГ).
Функция НоваяКоллекцияПечатныхФормСервер(Идентификаторы)

	Если ТипЗнч(Идентификаторы) = Тип("Строка") Тогда
		Идентификаторы = СтрРазделить(Идентификаторы, ",");
	КонецЕсли;

	Результат = Новый ТаблицаЗначений;
	Результат.Колонки.Добавить("ИмяМакета");
	Результат.Колонки.Добавить("ИмяВРЕГ");
	Результат.Колонки.Добавить("СинонимМакета");
	Результат.Колонки.Добавить("ТабличныйДокумент");
	Результат.Колонки.Добавить("Экземпляров");
	Результат.Колонки.Добавить("Картинка");
	Результат.Колонки.Добавить("ПолныйПутьКМакету");
	Результат.Колонки.Добавить("ИмяФайлаПечатнойФормы");
	Результат.Колонки.Добавить("ОфисныеДокументы");

	Для Каждого Идентификатор Из Идентификаторы Цикл
		Строка = Результат.Добавить();
		Строка.ИмяМакета   = Идентификатор;
		Строка.ИмяВРЕГ     = ВРег(Идентификатор);
		Строка.Экземпляров = 1;
	КонецЦикла;

	Возврат Результат;

КонецФункции
```

Ограничения: для прослеживаемых товаров используется базовая форма УПД
(варианты `_Прослеж` не задействованы); УПД печатается только если у
реализации есть счёт-фактура (иначе 500 с текстом причины).

## Шаг 4. Публикация

База уже опубликована (OData работает). В публикации на веб-сервере:

- HTTP-сервисы должны быть включены: в `default.vrd` публикации должен быть
  элемент `<httpServices>` с записью сервиса, например:

```xml
<service name="ПечатьДокументов"
        rootUrl="print"
        enable="true"
        reuseSessions="autouse"
        sessionMaxAge="20"
        poolSize="10"
        poolTimeout="5"/>
```

  (`name` — точное имя HTTP-сервиса в расширении; при переиздании публикации
  сервис добавляется автоматически, если в конфигураторе включено
  «Публиковать HTTP-сервисы расширений по умолчанию»);
- после публикации и `iisreset` проверка:

```bash
curl -u <логин>:<пароль> "http://192.168.3.2/InfoBase2/hs/print/invoice/<GUID счёта>" -o invoice.pdf
```

Признак работающего маршрута: `HTTP 200, application/pdf`, файл начинается с
`%PDF-`. Ошибка вида HTML-страницы IIS «404.0 Not found» — запрос не дошёл до
1С (сервис не опубликован), а ошибка `text/plain` с текстом 1С — дошёл
(смотрите текст).

## Шаг 5. Права

- В расширении создайте роль (например, `ПечатьPDF_HTTP`): право
  «Использование» на HTTP-сервис `ПечатьДокументов`, чтение/просмотр документов
  счёта, реализации и счёта-фактуры.
- Назначьте роль пользователю, под которым агент ходит в базу (обычно тот же,
  что для OData — у него уже есть права чтения).
- HTTP-сервис требует аутентификации: приложение передаёт ту же Basic-пару,
  что и для OData (настройка `print_service_url`, учётные данные базы).

## Подключение агента

В `.env` (глобально или в `ONEC_DATABASES` у конкретной базы):

```
ONEC_PRINT_SERVICE_URL=http://192.168.3.2/InfoBase2/hs/print
```

После этого:
- при создании счёта агент сам забирает PDF счёта и PDF УПД и прикладывает
  их к ответу чата (base64, файлы не сохраняются);
- по запросу пользователя PDF любого документа отдаёт Tool `export_document_pdf`.

PDF не хранятся на стороне приложения: существуют только внутри ответа.
