# onec-print-forms — печатные формы и PDF

## Когда использовать

- «Дай PDF счёта/УПД», «распечатай», «отправь клиенту документ».

## Проверенные возможности и ограничения (важно)

1. **Стандартный OData-интерфейс 1С печатные формы не отдаёт** — только данные (справочники, документы, регистры). В `$metadata` нет сущностей печатных форм; макеты и PDF недоступны.
2. **MCP `1c-odata` (если установлен) печатных форм тоже не предоставляет** — среди его инструментов нет формирования печатных форм и экспорта PDF (`docs/onec-capabilities.md`).
3. **Не имитируйте официальную печатную форму.** Сборка «похожего на счёт» HTML/PDF допустима только как черновик-предпросмотр для человека с явной пометкой «черновик, не заменяет печатную форму 1С».

## Что можно сделать сейчас

| Задача | Решение |
|---|---|
| Показать содержимое счёта/УПД | Прочитать документ + строки (Skills `onec-sales-invoices`, `onec-upd`) и вывести сводку: №, дата, реквизиты, позиции, суммы, НДС |
| Файл для человека | Черновик (Markdown/HTML) из данных документа + пометка «черновик» |
| Официальный счёт/УПД | Печатает человек из 1С (счёт — из документа «Счёт на оплату покупателю»; УПД — печатная форма «Реализации товаров и услуг») |

## Альтернативы, требующие доработки (зафиксировано как бэклог)

1. **HTTP-сервис в 1С** (расширение конфигурации): метод, формирующий печатную форму и возвращающий PDF. Требует доработки на стороне 1С.
2. **Внешняя обработка/расширение с фоновым экспортом PDF** в общую папку/S3 — аналогично.
3. **Веб-клиент 1С** — человек печатает вручную (сейчас единственный способ получить официальный PDF).
4. COM/`COMConnector` — вне текущей инфраструктуры.

## Проверка «корректности сформированного файла»

Применимо только к черновикам: сверяйте номер, дату, реквизиты (ИНН/КПП), каждую строку (содержание, количество, цена), итоги, ставку и сумму НДС — с документом 1С и правилами Skill `onec-validation`. Расхождение — файл не отдавать, показать расхождение.

## Ограничения

- Не обещайте пользователю PDF из 1С: официальная печатная форма — только из 1С; автоматизация — через доработку (выше).
- Не пытайтесь «печатать» POST-ами к произвольным URL сервера 1С — интерфейс не описан.
